Llistes en HTML

Veurem com fer llistes.

Hi trobam dos tipus de llistes: Les llistes Ordenades i les llistes No ordenades

Llistes ordenades: Aquestes llistes s'utilitzen per a llistes en que l'ordre dels elements és rellevant. Els elements es numeren automàticament (1, 2, 3, etc). Cada element de la llista es defineix amb l'etiqueta <"li">.
Per poder fer una llista ordenada, emprarem l'etiqueta <"ol">.


Llistes No ordenades: Aquestes llistes s'utilitzen per fer llistes sense un ordre específic. Els elements es mostren amb vinyetes o altres símbols abans de cada ítem. Cada element de la llista es defineix també amb l'etiqueta <"li">.
Per poder fer una llista No ordenada, emprarem l'etiqueta <"ul">.

Exemple llista ordenada:

  1. Patates
  2. Olives
  3. Fuet

Exemple llista No ordenada:

  • Patatilla
  • Olivetes
  • Pipes
